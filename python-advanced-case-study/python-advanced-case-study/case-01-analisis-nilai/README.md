# Case 01 — Analisis Nilai Mahasiswa

## Masalah yang diselesaikan
Program menghitung nilai akhir mahasiswa berdasarkan bobot tugas 30%, UTS 30%, dan UAS 40%. Program menampilkan ranking, mahasiswa berprestasi dengan nilai akhir di atas 80, dan mahasiswa peringkat pertama.

## Konsep Python
- **List comprehension:** membuat data mahasiswa yang sudah memiliki nilai akhir.
- **Lambda function:** menentukan kunci pengurutan berdasarkan nilai akhir.
- **Filtering:** memilih mahasiswa yang nilai akhirnya lebih dari 80.
- **Sorting:** mengurutkan nilai dari tertinggi ke terendah menggunakan `sorted()`.

## Cara menjalankan
```bash
python main.py
```
