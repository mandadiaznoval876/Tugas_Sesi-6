## Ringkasan
Repository ini berisi penyelesaian tiga studi kasus:

1. **Case 01 — Analisis Nilai Mahasiswa:** menghitung nilai akhir dengan bobot tugas 30%, UTS 30%, dan UAS 40%, memfilter nilai di atas 80, mengurutkan ranking, dan menampilkan mahasiswa terbaik. Menggunakan list comprehension, lambda, filtering, dan sorting.
2. **Case 02 — Streaming Data Sensor IoT:** menghasilkan data suhu secara bertahap dengan `yield`, membaca data satu per satu, dan mengategorikan suhu tanpa menyimpan seluruh data ke list.
3. **Case 03 — Sistem Keamanan Akun & Audit Log:** memvalidasi username/password dengan RegEx, memakai class `User` dan `@property`, serta decorator untuk mencatat percobaan login.

## Cara menjalankan
Pastikan Python 3 sudah terpasang. Masuk ke folder kasus yang ingin dijalankan, lalu jalankan:

```bash
python main.py
```

Semua program menggunakan pustaka standar Python sehingga tidak memerlukan instalasi paket tambahan.
